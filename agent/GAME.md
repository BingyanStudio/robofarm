# Game

本文档详细描述游戏的游玩方法


## 基础机制

1. 回合制: 游戏按照回合制执行，每一个回合，玩家提供的代码执行一次，并返回一个 "无人机操作", 无人机执行该操作

2. 地图: 由正方形 Tile 构成，包括
   1. 土地: 可以在上面种植 **陆生** 作物
   2. 水池: 可以在上面种植 **水生** 作物; 无人机可以取水
   3. 沙地: 可种植草莓/葡萄/南瓜/西瓜/紫云英, 生长所需周期 ×1.5 (向下取整, 西瓜不受影响)
   4. 未来可能添加新的地块种类，因此需要留接口 (数据在 shared/src/registry.ts 的 TILES)
   地图左上角的 Tile 坐标为 (0, 0), x 轴向右, y 轴向下 建立坐标系

3. 无人机: 代码控制的主要单位
   1. 根据游戏模式不同，可能有不止一个无人机能被控制
   2. 无人机可以执行:
      1. 获取信息: 获取地图范围、自身位置、各个 Tile、所有作物、对方无人机等信息
      2. 移动: 移动到周围 8 格之一, 不能移动到地图外，或已有无人机的 Tile。若两个无人机回合结束时将要移动到同一个 Tile, 则按照 **代码执行时间短** 优先 进行仲裁
      3. 种植: 花费金钱，在当前所在 Tile 种植作物
      4. 取水: 若当前在 **水池** 上，则可以取水，最多存储 5 格水
      5. 浇水: 植物在生长时可能因缺水而停止生长, 无人机需要移动到植物所在 Tile 并浇水，每次浇水消耗 1 格水
      6. 收获: 收获成熟的作物，赚取金钱
      7. 铲除: 铲除当前格作物
   3. 能量: 无人机拥有能量储量 (上限 10, 初始 0), 通过 Charge 原地充能 (+5), 供行/列范围操作消耗
   4. 行/列范围操作 (需消耗能量):
      1. HarvestRow / HarvestCol: 一次性收割所在行/列的全部成熟作物, 消耗 4 能量; 竞技模式仅收割自己半场
      2. WaterRow / WaterCol: 给所在行/列浇水, 按 左→右 / 上→下 顺序直到水耗尽, 跳过不需浇水的作物, 消耗 3 能量
      3. InterceptRow / InterceptCol: 回合结束时拦截所在行/列全部携带偷菜资金的对方无人机, 消耗 6 能量 (竞技模式)
      4. ChangeTile: 消耗 3 能量将脚下地块转换为 soil/water/sand, 前提是上下左右至少有一个同类型地块 (不允许凭空创造)
   5. 上述操作均由 Typescript API 提供

4. 作物
    1. 作物拥有如下的状态:
        1. 生长: 正在生长，在固定的回合数后成熟
        2. 干旱: 需要浇水，若没有及时浇水则植物将不会继续生长

5. 代码执行: 有如下限制条件
    1. API: 不允许玩家调用任何网络、系统等无关且有风险的 API
    2. 资源: 限制玩家程序的 CPU & 内存占用, 内存超出则立即 kill 并报错
    3. 时间: 限制玩家程序执行时间为 0.4s, 超时则立即 kill 并报错
    4. 所有玩家程序产生的效果都是 **同时发生** 的。如果有两个无人机冲突(如同时进入一格)，则 **程序执行时间短** 的无人机优先执行指令，另一个取消当前回合指令


## 单人模式

单人模式下，玩家需要编写程序，在限定的回合数内赚取尽可能多的金钱。每局初始资金为 20 金钱。

1. 地图: 单人模式的地图为 7 * 7 大小, 有如下布局:
    1. 玩家出生点为 (3, 3) 即地图中心
    2. 水池: (1, 1), (2, 1), (1, 2), (4, 4), (4, 5), (5, 4), (5, 5)
    3. 沙地: (0, 0) 到 (6, 1) 以及 (0, 2) 到 (2, 3) 的土地 (水池位置不变)
    4. 其余 Tile 均为土地
    当前地图为固定, 但未来可能会每次进入游戏从后端取得最新的单人模式地图

2. 回合制: 单人模式固定 300 回合。若玩家开始游戏，则代码按照 300 回合执行。正常播放速度下, 回合间隔为 0.8s (无论玩家程序执行时间)，快进则为 0.5s

3. 代码上传与排行榜: 玩家必须将代码上传到服务器，由服务器验证执行后，所得金钱进入排行榜。流程如下:
    1. 登录: 若玩家尚未通过 Github 登录，则要求玩家登录
    2. 检查: 若玩家已经有一个正在运行的代码，则不允许上传下一个
    3. 运行: 服务器接受玩家代码，连续执行 (即: 上一回合好了立刻进入下一回合执行，不再等待到 1s)
    4. 结果: 若游戏正常结束, 则记录玩家的最终金钱进入排行榜; 否则，返回报错信息到前端
    5. 排行: 按照分数由高到低排行


## 多人竞技

多人竞技模式下，玩家需要编写代码，使其在运营自己农场的同时, 通过偷菜等方式干扰对手农场, 最终金钱高者获胜。双方各有 20 金钱开局。

1. 地图: 多人模式地图为 14 * 7 大小:
    1. 我方无人机出生点为 (3, 2) 和 (3, 4)，即两架无人机出生在中心上方和下方 1 格
    2. 地图左半 7 * 7 和单人模式相同，右半 7 * 7 为单人模式镜像
    3. 对方视角是我方视角的镜像, 即在对方屏幕上，其无人机也出生在 (3, 2), (3, 4), 因此双方只需要按照同一个坐标系进行编程，即可实现对战
    4. 左侧 7 * 7 为 **我方半场**, 右侧 7 * 7 为 **对方半场**

2. 偷菜机制: 增加 "偷菜" 机制，具体如下:
    1. 若我方无人机在 **对方半场** 收获了作物, 所得金钱将进入该无人机的临时资金池
    2. 若我方无人机返回我方半场，则该资金池立即加入我方总金钱
    3. 若我方无人机返回前，对方执行 "拦截" 且命中，则临时资金池清空，资金返还给对手; "拦截" 将在下文说明

3. 无人机部分功能修改:
    1. 种植: 可在 **任意半场** 使用 (可到对方半场占位种植, 占用对方地块)
    2. 铲除: 仅能在 **我方半场** 使用
    3. 拦截: 指定一个 Tile 进行拦截，若一个已经偷菜的对手无人机在**该回合结束时**进入这个位置，则将其偷菜所得金钱全部返还。
    4. 行/列范围操作: 收割整行/列仅限自己半场; 拦截整行/列可拦截对应行/列全部携带偷菜资金的对方无人机

3. 多人竞技固定 300 回合。若玩家开始游戏，则代码按照 300 回合执行。正常播放速度下, 回合间隔为 0.8s (无论玩家程序执行时间)，不允许快进

4. 匹配机制: 
    1. 玩家要想多人对战，必须先上传自己的 "出战代码"
    2. 匹配对手时，玩家会进入一个列表视图，每一项都是其他玩家的出战代码，玩家可以选择一个进行挑战
    3. 挑战时，代码在服务器执行，服务器保存对战的过程并向前端发送
    4. 结束后，其他玩家的出战代码会记录胜 / 败数量
    5. 保存的对战过程，可以由交战双方玩家在 "历史记录" 中看到，并播放对战回放
    6. 其他玩家的代码 **始终保持不可见**，防止剽窃

6. 模拟对战: 一种离线模式, 允许一个玩家给敌我双方分别指定代码，并在浏览器内运行, 以进行模拟对战


## 无人机 API

1. 玩家程序的入口函数: 

```Typescript
// 无人机操作基接口
interface DroneOperation {}

// TODO: 增加各个无人机子操作


// 玩家程序入口
function run(droneId: Int) : DroneOperation {
    // 由玩家实现
}
```

2. 数据类型: 

```Typescript
// Drone 信息
interface DroneInfo {
    position: (number, number); // 当前坐标
    water: number;              // 当前含水量

    isOpponent: boolean;        // 是否是对方的无人机
    bounty: number;             // 对方无人机偷菜所得金额
}

// Tile 信息
enum TileType {
    Soil,
    Water
}

interface TileInfo {
    type: TileType
    hasCrop: boolean
}

// 作物信息
enum CropType {
    Strawberry, // 草莓
    Grape,      // 葡萄
    Wheat,      // 小麦
    Lotus,      // 荷花
    Pumpkin,    // 南瓜
}

enum CropState {
    Growing,    // 正在生长
    Thristy,    // 需要浇水
    Grown,      // 成熟
}

interface CropInfo {
    type: CropType;
    state: CropState;
    cyclesToGrown: number   // 还需要多少周期长成, 仅在 state == Growing 有效
}

```

3. 功能接口
```Typescript
// 获取自身情况
function getSelf() : DroneInfo

// 获取指定格子的无人机情况
function getDrone(position: (number, number)) : DroneInfo

// 获取指定格子信息
function getTile(position: (number, number)) : DroneInfo

// 获取指定格子作物信息
function getCrop(position: (number, number)): DroneInfo
```
