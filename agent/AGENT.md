# RoboFarm

RoboFarm 计划成为一个编程类农场游戏。玩家需要编写代码，控制游戏内的无人机进行种植、收获等任务，在限定的回合数内赚取最多的资金。


## 架构

游戏项目计划采用 **前后端完全分离** 的架构实现。其中
- 前端: 负责画面渲染、本地运行代码、回放等功能，并在必要时连接到后端实现联机相关功能
- 后端: 负责验证玩家代码执行结果 (若玩家想要提交排行榜，则需要将代码交给后端执行，防止前端作弊), 以及联机竞技模式下，本地运行竞技双方玩家代码，并向前端推送每一回合的执行结果 (以实现竞技直播)


## 技术选型

项目前端、后端均使用 Typescript 编写; 同时，玩家也通过 Typescript 编写代码控制无人机。

需要保证玩家编写的 Typescript 代码在前端、后端的执行结果相同


## 代码规范

1. 复用性: 代码应当具备 **高度的可复用性**，相同的逻辑应当仅编写一份 (防止后续需要修改时出错)
2. 拓展性: 代码应当 **模块化可拓展**，不允许使用 if 硬编码进行特例处理
3. 规范性: 代码应当能通过 linter 与 formatter 检查


## 项目描述

- `GAME.md`: 游戏主体描述, 包括游戏玩法、不同游戏模式、游戏内编程 API 等
- `FRONTEND.md`: 项目前端的架构与功能
- `BACKEND.md`: 项目后端的架构与功能，以及向前端提供的 API
