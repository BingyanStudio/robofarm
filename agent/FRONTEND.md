# Frontend

本文档描述游戏前端的结构与功能


## 全局

1. 右上角显示 Github 登录状态
2. 在需要的时候，能跳转到 Github 登录界面，并获取相应鉴权 Token


## 1. 开始界面

开始界面是玩家访问 url 看到的第一个界面，包含:
1. 游戏标题
2. 游戏简要介绍
3. 开始按钮: 按下后进入主菜单


## 2. 主菜单

主菜单提供 3 个按钮: 
1. 单人模式: 按下后进入单人模式界面
2. 模拟竞技: 按下后进入模拟竞技模式界面
2. 多人竞技: 按下后进入多人竞技匹配界面
3. API 手册: 按下后进入 API 手册界面


## 3. 单人模式

单人模式界面有如下布局: 

1. 代码框: 左侧 35% 为代码框，拥有行号显示、行高亮、简单语法补全等功能; 其中的代码通过 localstorage 存储
2. 游戏界面: 右侧剩余部分为游戏画布，可以缩放、拖拽观察游戏场地情况
3. 日志界面: 底部，长 100%, 高 10%, 显示程序日志和报错
4. 开始、步进、重启按钮，回合计数器: 位于游戏界面下方，图标按钮，按下后分别执行对应功能
5. 提交按钮: 
    1. 未登录时: Tooltip 显示需要登录
    2. 有一个程序正在服务器运行: disable, 不允许点击


## 4. 模拟竞技

模拟竞技有如下布局:

1. 完全复用单人模式的布局 (代码层面复用)
2. 代码框分为 2 个 Tab, 可切换，左 Tab 用于给我方无人机编程，右 Tab 用于给对方无人机编程
3. 取消提交按钮


## 5. 多人竞技匹配页面

1. 代码框: 左侧 35% 为代码框，拥有行号显示、行高亮、简单语法补全等功能; 其中的代码通过 localstorage 存储，且与模拟竞技同步
2. 上传按钮: 位于代码框底部点击则上传代码框内的代码为出战代码
3. 瀑布流，显示数据库已有的全部上传代码，按照胜率从高到低排序，不显示代码内容，仅显示玩家名称和胜败数量，点击一个，即可进入战斗界面


## 6. 多人竞技页面

1. 完全复用单人模式的布局 (代码层面复用)
2. 代码框不可编辑, 内部显示当前出战的代码
3. 取消步进、重启、提交按钮
4. 开始按钮功能修改: 按下后则给服务器发送信号, 服务器开始推演
5. 与服务器建立 websocket, 接收服务器传回的战斗情况并渲染到游戏界面


## 7. 回放页面

1. 游戏界面: 显示游戏内容 (支持根据游戏模式切换单人和多人地图)
2. 开始、步进、步退、加速、减速、重启按钮: 对应回放功能


## 8. 观战界面

1. 列出当前全部的多人竞技房间
2. 可以选择房间进入
3. 进入后显示游戏界面，接受后端传过来的信息渲染
